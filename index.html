¿Cómo instalar el archivo APK en tu celular?

Guía rápida de 3 pasos para instalar la aplicación en dispositivos Samsung, Xiaomi, Motorola y otros.

1
Descargar el Instalador

Presiona el botón de descarga o escanea el código QR. Si el navegador pregunta: "¿Descargar este archivo potencialmente dañino?", elige "Descargar de todos modos" (alerta estándar de Android para apps fuera de Play Store).

2
Permitir Orígenes Desconocidos

Abre el archivo descargado desde las notificaciones o la carpeta Descargas. Si aparece el aviso de seguridad, pulsa "Ajustes" y activa la casilla "Permitir desde esta fuente".

3
Instalar y Abrir LexIA

Presiona "Instalar". Una vez completado, pulsa "Abrir". La aplicación te llevará directamente al Catálogo de Leyes e iniciará en modo autónomo.
